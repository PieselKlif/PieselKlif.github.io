## Na temat projektu
Oficjalny kod źródłowy mojej strony internetowej / portfolio. Strona prezentuje moje podejście do tworzenia aplikacji webowych, wybrany stos technologiczny oraz dotychczasowe projekty komercyjne i edukacyjne.

## Główne cechy strony

- **Semantyczny HTML5:** Kod pisany z dbałością o standardy i prostą strukturę (DOR / BEM).
- **Czysty i zoptymalizowany styl:** Wykorzystanie SCSS do sprawnego zarządzania arkuszami stylów.
- **Dostępność i wydajność:** Brak zbędnych zależności zewnętrznych – szybkie ładowanie i wysoki wynik w Lighthouse.
- **Responsywność (RWD):** Dostosowanie interfejsu do urządzeń mobilnych oraz ekranów desktopowych.


## Jak uruchomić projekt lokalnie

1. Sklonuj repozytorium na swój dysk:
```bash
git clone https://github.com/PieselKlif/PieselKlif.github.io.git

```

2. Przejdź do katalogu projektu:
```bash
cd PieselKlif.github.io

```


3. Otwórz plik `index.html` bezpośrednio w przeglądarce lub uruchom go przy użyciu rozszerzenia **Live Server** w VS Code.
